# Data Structures & Algorithms

A collection of data structures and algorithms implemented from
scratch as part of my study of computer science.

The goal of this repository is to improve my understanding of how
common data structures and algorithms work internally, rather than
relying solely on built-in implementations.

## Implemented

### Data Structures

- Stack
- Queue
- Singly Linked List
- Stack using a Linked List

### Algorithms

- Bubble Sort
- Insertion Sort
- Selection Sort
- Quick Sort
